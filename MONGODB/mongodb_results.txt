4. INDEX PERFORMANCE COMPARISON

Search condition: January 2025 records

Metric                  Indexed Search    Collection Scan
Records found           29                29
Execution time          169.0366 ms       129.6801 ms
Keys examined           29                0
Documents examined      29                160

Observation:
The indexed search examined only 29 documents, whereas
the collection scan examined all 160 documents.
The collection scan was faster in this test because the
collection contains a relatively small number of records.
Indexing reduced the number of documents examined but
did not reduce the measured execution time in this run.

5. WHY MONGODB WAS SELECTED

MongoDB is a NoSQL document database that stores data
in flexible JSON-like documents.

It was selected because:
- It supports flexible data structures.
- It handles semi-structured agricultural market data.
- It supports fast document retrieval and filtering.
- It provides indexing for frequently queried fields.
- It can support dashboard applications and scalable data storage.
